# Exploração de Carteira

Dashboard interativo desenvolvido em Python com Streamlit para acompanhamento, segmentação e gestão de status de contas (Clientes e Prospecção).

## 📌 Funcionalidades

* **Filtros dinâmicos:** Segmentação por Unidade, Conta e Responsável.
* **Métricas e Indicadores:** Agrupamento por níveis de prioridade (A - Prioritário, B - Relevante, C - Não Prioritário).
* **Gestão de Recorrência:** Classificação automática do status da conta (Ativo, Em Risco, Inativo) com base no tempo de última interação.
* **Visualização detalhada:** Tabelas estruturadas com histórico de faturamento, contratos, timesheet e reuniões.

## 🛠️ Tecnologias Utilizadas

* **Python**
* **Streamlit**
* **Pandas**
* **Plotly**
